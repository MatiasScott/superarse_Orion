# Orion

SIGA / ERP Academico del Instituto Superior Tecnologico Superarse.

## XAMPP

Ubicacion:

`C:\xampp\htdocs\superarse_Orion`

1. Copia `.env.example` como `.env`.
2. Ejecuta `composer install`.
3. Crea/importa `superarse_siga`.
4. Abre `http://localhost/superarse_Orion/public/`.

Microsoft SSO queda desactivado inicialmente en local.
